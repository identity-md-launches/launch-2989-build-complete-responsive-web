Squeek Radar

Know what's happening on the wheel

Squeek Radar needs JavaScript to load live data from the Squeekchain API.

Data from the public Squeekchain API (api.squeekchain.com/v1, Sepolia deployment). Read-only: no wallet, staking or tokens.

Accepted measurements are device-signed and not SqueekCore-certified. Only settlements marked confirmed have settled on-chain.
